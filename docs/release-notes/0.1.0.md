### 0.1.0 {small}`the-future`

First public release of GATAC: GPU-accelerated single-cell ATAC-seq analysis,
from fragment files to footprints, built on RAPIDS. It covers:

- Fragment files in a compact Parquet format ({doc}`gatac.io </api/io>`)
- QC metrics, doublet detection, and tile and gene matrices ({doc}`gatac.pp </api/preprocessing>`)
- Spectral embedding and ArchR-style iterative LSI ({doc}`gatac.dr </api/dr>`)
- MACS3 peak calling and marker peaks ({doc}`gatac.peak </api/peak>`)
- Motif enrichment, GSEA and chromVAR ({doc}`gatac.motif </api/motif>`)
- TOBIAS footprinting and differential TF binding ({doc}`gatac.tobias </api/tobias>`)
- The {doc}`gatac command line </cli/index>`, and {doc}`extensions </extensions>` that plug into both
