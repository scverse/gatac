### 0.2.0 {small}`the-future`

```{rubric} Features
```

- Add {func}`~gatac.io.read_h5ad`, which reads an `.h5ad` file like {func}`anndata.io.read_h5ad` and decompresses the sparse matrices on the GPU. With `to_gpu=True` it returns cupy matrices for rapids-singlecell.
- Add {func}`~gatac.io.write_h5ad`, which writes AnnData objects the way GATAC writes count matrices.
- Accept a backed AnnData, or a view of one, in {func}`~gatac.dr.spectral`, {func}`~gatac.motif.compute_deviations`, {func}`~gatac.peak.markers` and {func}`~gatac.pp.select_features`. The matrix is read from disk onto the GPU in chunks, without loading it into memory. See [count matrices on disk](/api/io.md#count-matrices-on-disk).
- Add `compression` to the functions that write count matrices, and `--compression` to the matching commands.

```{rubric} Performance
```

- Store count matrices with int32 indices and gzip compression. A tile matrix of 530,000 cells now takes 4 GB on disk instead of 32 GB.
- Run {func}`~gatac.dr.spectral` on a backed tile matrix with 3 GB of host memory, about 3× faster than loading the file with `scanpy.read_h5ad` first.
- Read the count matrix once in {func}`~gatac.motif.compute_deviations` instead of once per batch of motifs. On a backed peak matrix of 530,000 cells, it runs 3× faster and uses 4 GB of host memory instead of 120 GB.

```{rubric} Bug fixes
```

- {func}`~gatac.motif.compute_deviations` raises an error when `varm["bg_peaks"]` points to peaks that are no longer in the matrix, instead of reading the wrong peaks.

```{rubric} Misc
```

- Count matrices are gzip-compressed by default. GATAC reads them as fast as uncompressed ones, but `anndata.read_h5ad` takes several times longer.
- `anndata.read_h5ad` returns int32 indices for matrices written by GATAC, instead of int64.
- `kvikio` is now part of the `rapids-cu12` and `rapids-cu13` extras.
- GATAC follows the [cookiecutter-scverse](https://github.com/scverse/cookiecutter-scverse) template and is linked to it with cruft, so later template changes come in with `cruft update`. The source moves to `src/gatac`; the installed package is unchanged.
- The documentation uses the scverse theme and the shared scverse sidebar, with a new {doc}`quickstart </quickstart>` and {doc}`citation </citation>` page.
- mypy now checks the package and the tests, and the template's ruff rules apply. Results are unchanged.
